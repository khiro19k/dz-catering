# DZ CATERING - Dossier des Photos de Plats & Créations Culinaires

Déposez ici vos photos haute définition pour la **Table de Dégustation Royale**.

### Recommandations pour un rendu prestigieux :
- **Format** : PNG avec fond transparent (détouré) ou JPG haute résolution centré sur une assiette.
- **Angle** : Prise de vue du dessus (Top-Down / vue zénithale) ou vue 45° épurée.
- **Dimensions suggérées** : 800x800px ou carré (1:1).

### Noms de fichiers suggérés :
- `verrine-saumon.png` (Verrines fraîches crevettes & saumon)
- `canapes-salés.png` (Canapés salés prestige)
- `macarons-mignardises.png` (Macarons parisiens & mignardises)
- `patisserie-orientale.png` (Gâteaux traditionnels orientaux)
- `brochettes-gourmandes.png` (Brochettes cocktail)
- `jus-cocktails.png` (Cocktail de fruits frais)
